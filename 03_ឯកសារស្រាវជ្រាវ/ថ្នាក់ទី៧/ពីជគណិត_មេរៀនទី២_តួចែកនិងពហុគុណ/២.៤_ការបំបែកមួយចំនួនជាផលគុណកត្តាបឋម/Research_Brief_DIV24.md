# សំយោគការស្រាវជ្រាវគរុកោសល្យ (Research Brief — `DIV24`)

- **មុខវិជ្ជា និងថ្នាក់**៖ គណិតវិទ្យា ថ្នាក់ទី៧ — មេរៀនទី២៖ តួចែកនិងពហុគុណ
- **ចំណងជើងរង (១ ម៉ោងសិក្សា = ៥០ នាទី)**៖ `៤. ការបំបែកមួយចំនួនជាផលគុណកត្តាបឋម` (សៀវភៅសិក្សាគោល ទំព័រ ២០ និងលំហាត់ទំព័រ ២៤ លេខ ៥)
- **បរិបទថ្នាក់រៀន**៖ គ្មានស្លាយ/LCD Projector និងគ្មានសម្ភារៈកាត់បិទ — ប្រើប្រាស់ **សន្លឹកកិច្ចការសិស្សបំពេញចន្លោះ ស-ខ្មៅ (ប្រៀបធៀបចែកឈរទល់នឹងដ្យាក្រាមដើមឈើ)** + **ប្លង់ក្ដារខៀន ៣ ផ្នែក**។

## ៣. ផែនទីបម្លែងចូលគំរូ 5Es (៥០ នាទី)

- **ជំហានទី១ (២ នាទី)**៖ រដ្ឋបាលថ្នាក់ រៀបក្រុម ៣ នាក់ និងចែកសន្លឹកកិច្ចការ `DIV24`។
- **ជំហានទី២ (៩ នាទី)**៖ កំណែកិច្ចការផ្ទះទំ.២៤ លេខ ៤ ($\le 3\text{ នាទី}$) + រំលឹកចំនួនបឋមតូចៗ $2, 3, 5, 7, 11, 13$ ($3\text{ នាទី}$) + `E1 - Engage` អន្ទាក់ $36 = 4\times 9$ ទល់នឹង $36 = 2^2\times 3^2$ ($3\text{ នាទី}$).
- **ជំហានទី៣ (១៧ នាទី)**៖
  - `E2 - Explore (១១ នាទី)`៖ `E2-A` បំបែក $30$ តាមវិធីទី 1 (ចែកឈរ) និងវិធីទី 2 (ដ្យាក្រាមដើមឈើ) តាមទំ.២០ + `E2-B` បំបែក $72$ ជាទម្រង់ស្វ័យគុណ $2^3\times 3^2$។
  - `E3 - Explain (៦ នាទី)`៖ សង្ខេបវិធានទូទៅ (ទំ.២០) និងធនាគារហេតុផល `①–④`។
- **ជំហានទី៤ (២០ នាទី)**៖
  - `E4 - Elaborate (១០ នាទី)`៖ លំហាត់គំរូ ក និង ខ ទំ.២០ ($x=180,\ y=360$ និង $x+y=540$) + `EIA Looking-Back`។
  - `E5 - Evaluate (១០ នាទី)`៖ ប្រតិបត្តិទំ.២០ (បំបែក $66$ និង $273$) + បិទបេសកកម្ម `E1` + សំណួរវិនិច្ឆ័យ `A–D` + សំបុត្រចេញ ៦០ វិនាទី ($90$)។
- **ជំហានទី៥ ($\le$ ២ នាទី)**៖ កិច្ចការផ្ទះទំ.២៤ លេខ ៥ និងបណ្ដាំផ្ញើអានមុនចំណុច `៥. តួចែករួមធំបំផុត (PGCD)` (ទំ.២១)។
