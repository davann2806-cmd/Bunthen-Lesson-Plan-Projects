# សំយោគការស្រាវជ្រាវគរុកោសល្យ (Research Brief — `DIV23`)

- **មុខវិជ្ជា និងថ្នាក់**៖ គណិតវិទ្យា ថ្នាក់ទី៧ — មេរៀនទី២៖ តួចែកនិងពហុគុណ
- **ចំណងជើងរង (១ ម៉ោងសិក្សា = ៥០ នាទី)**៖ `៣. ចំនួនបឋម និងចំនួនមិនបឋម` (សៀវភៅសិក្សាគោល ទំព័រ ១៩ និងលំហាត់ទំព័រ ២៤ លេខ ៤)
- **បរិបទថ្នាក់រៀន**៖ គ្មានស្លាយ/LCD Projector និងគ្មានសម្ភារៈកាត់បិទ — ប្រើប្រាស់ **សន្លឹកកិច្ចការសិស្សបំពេញចន្លោះ ស-ខ្មៅ (រួមទាំងតារាងកញ្ច្រែងអេរ៉ាតូស្ដែន $1\text{--}50$)** + **ប្លង់ក្ដារខៀន ៣ ផ្នែក**។

## ៣. ផែនទីបម្លែងចូលគំរូ 5Es (៥០ នាទី)

- **ជំហានទី១ (២ នាទី)**៖ រដ្ឋបាលថ្នាក់ រៀបក្រុម ៣ នាក់ និងចែកសន្លឹកកិច្ចការ `DIV23`។
- **ជំហានទី២ (៩ នាទី)**៖ កំណែកិច្ចការផ្ទះទំ.២៤ លេខ ១ និង លេខ ៣ ($\le 3\text{ នាទី}$) + រំលឹកការរកតួចែក ($3\text{ នាទី}$) + `E1 - Engage` អន្ទាក់គូ/សេស និងលេខ $1, 2, 9$ ($3\text{ នាទី}$).
- **ជំហានទី៣ (១៧ នាទី)**៖
  - `E2 - Explore (១១ នាទី)`៖ `E2-A` រាប់ចំនួនតួចែកនៃ $5, 14, 15, 23$ និង $1$ (ទំ.១៩) + `E2-B` បំណកស្រាយកញ្ច្រែងអេរ៉ាតូស្ដែនលើចំនួន $1\text{--}20$។
  - `E3 - Explain (៦ នាទី)`៖ សង្ខេបនិយមន័យ «ជាទូទៅ» និង «សម្គាល់» (ទំ.១៩) ភ្ជាប់ធនាគារហេតុផល `①–④`។
- **ជំហានទី៤ (២០ នាទី)**៖
  - `E4 - Elaborate (១០ នាទី)`៖ លំហាត់គំរូ ក និង ខ ទំ.១៩ + សំណួរឆ្លុះបញ្ចាំង `EIA Looking-Back` ($11^2 = 121 > 50$)។
  - `E5 - Evaluate (១០ នាទី)`៖ ប្រតិបត្តិទំ.១៩ (កញ្ច្រែងអេរ៉ាតូស្ដែនរកចំនួនបឋម $< 50$ ទាំង $15$ ចំនួន) + បិទបេសកកម្ម `E1` + សំណួរវិនិច្ឆ័យ `A–D` + សំបុត្រចេញ ៦០ វិនាទី។
- **ជំហានទី៥ ($\le$ ២ នាទី)**៖ កិច្ចការផ្ទះទំ.២៤ លេខ ៤ និងបណ្ដាំផ្ញើអានមុនចំណុច `៤. ការបំបែកមួយចំនួនជាផលគុណកត្តាបឋម` (ទំ.២០)។
