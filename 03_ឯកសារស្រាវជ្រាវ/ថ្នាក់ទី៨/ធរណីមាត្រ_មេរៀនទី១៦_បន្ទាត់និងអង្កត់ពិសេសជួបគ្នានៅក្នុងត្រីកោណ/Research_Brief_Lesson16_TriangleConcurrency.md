## ២. កំហុសបោះពុម្ពក្នុងសៀវភៅគោល (MoEYS Textbook Errata) ដែលត្រូវកែតម្រូវក្នុងមេរៀន

1. **ទំព័រ ២០៦ (`លំហាត់គំរូ` ១៦.១)**: សរសេរ `តាង A', B' និង C រៀងគ្នាជាចំណុចកណ្ដាល...` (ភ្លេចសញ្ញា `'` លើ `C'`) — កែតម្រូវជា `C'`។
2. **ទំព័រ ២០៨ (`ប្រតិបត្តិ` ១៦.២)**: សរសេរ `កាត់គ្នាត្រង់ A, B' និង C'` (ភ្លេចសញ្ញា `'` លើ `A'`) — កែតម្រូវជា `កាត់គ្នាត្រង់ A', B' និង C'`។
3. **ទំព័រ ២១០ (`ប្រតិបត្តិ` ១៦.៣) និងទំព័រ ២១៤ (`លំហាត់ទី១១`)**: ប្រធានដូចគ្នាទាំងស្រុង — ប្រើជាលំហាត់ប្រតិបត្តិក្នុងម៉ោង `CONC3` ហើយជ្រើសលំហាត់ #4, #9, #10 ជាកិច្ចការផ្ទះដើម្បីកុំឱ្យស្ទួន។
4. **ទំព័រ ២១៣ (`លំហាត់ទី៧`)**: រូបភាពបង្ហាញចម្ងាយកែងស្មើគ្នា $1\text{ cm}, 1\text{ cm}, 1\text{ cm}$ ពីចំណុច $M$ ទៅជ្រុងទាំងបីនៃ $\triangle ABC$ ($\angle A = 80^\circ$, ហើយមុំពុះត្រង់ $B$ ដាក់ $40^\circ$ ឬ $\angle B=40^\circ$) — ក្នុងសន្លឹកកិច្ចការបញ្ជាក់សញ្ញាមុំឱ្យច្បាស់លាស់ ($\angle ABM = 20^\circ$ ឬ $\angle ABC = 40^\circ \Rightarrow \angle C = 60^\circ \Rightarrow \angle BMC = 130^\circ$, ឬបើ $\angle ABM = 40^\circ \Rightarrow \angle B = 80^\circ \Rightarrow \angle C = 20^\circ \Rightarrow \angle BMC = 130^\circ$ ដូចគ្នាគួរឱ្យភ្ញាក់ផ្អើល ព្រោះ $\angle BMC = 90^\circ + \frac{\angle A}{2} = 90^\circ + 40^\circ = 130^\circ$ មិនអាស្រ័យនឹង $\angle B$ ឡើយ!)។
