ការពិនិត្យផ្ទាល់លើទំព័រដើម `pdf_p159.png`, `pdf_p160.png`, `pdf_p161.png`, `pdf_p170.png` និងរូបពង្រីក `300 dpi` បានបញ្ជាក់ខ្លឹមសារគោល និងកំហុសបោះពុម្ព/រូបភាពយ៉ាងច្បាស់ដូចខាងក្រោម (ក្រុមអ្នកនិពន្ធ Wave 2/3 ត្រូវដោះស្រាយឱ្យបានគ្រប់ចំណុច)៖

1. **§1.3.2 ខ. អ៊ីប៉ូតេនុសប៉ុនគ្នា និងជ្រុងមុំកែងមួយប៉ុនគ្នា (អ.ជ / HL) — ទំព័រ `១៥៤–១៥៥` (`pdf_p159.png`, `pdf_p160.png`)**:
   - **សម្រាយឧទាហរណ៍ និងកំហុសបោះពុម្ពទាំង ៣ ចំណុចលើទំព័រ `១៥៤`**:
     - **កំហុស ១a (`Vertex / Leg Swap`)**: ដង្កៀបសម្មតិកម្មដាក់ $\angle A = \angle A' = 90^\circ$, $AB = A'B'$, $BC = B'C'$ ហើយ**រូបខាងលើ**ដាក់កំពូល $B, B'$ នៅខាងលើ ដោយមានសញ្ញា `|` លើជ្រុងឈរ $AB, A'B'$ ($C, C'$ នៅខាងឆ្វេងក្រោម, $A, A'$ នៅខាងស្ដាំក្រោម, `//` លើ $BC, B'C'$)។ អត្ថបទសរសេរថា *«ដោយ $AB = A'B'$ យើងអាចត្រឡប់ហើយដាក់ជ្រុង $A'C'$ ត្រួតលើជ្រុង $AC$»* — ប៉ុន្តែ**រូបកណ្ដាល** និង**រូបខាងក្រោម** បែរជាប្ដូរ $B \leftrightarrow C$ និង $B' \leftrightarrow C'$ ដាក់កំពូល **`C, C'`** នៅខាងលើ និងដាក់សញ្ញា `|` លើជ្រុងឈរ **`AC, A'C'`** វិញ រួចផ្គុំចេញជា `C(C')` លើ, `A(A')` ក្រោម, `B` ឆ្វេង, `B'` ស្ដាំ ដើម្បីបង្ហាញ $\angle BAB' = 90^\circ + 90^\circ = 180^\circ$ ($\Rightarrow BB'$ ជាបន្ទាត់ត្រង់) និង $\triangle BCB'$ សមបាទ ($\Rightarrow \angle B = \angle B'$)។ *(Wave 2/3 ត្រូវគូស TikZ ឱ្យអក្សរកំពូល និងគំនូស `|` ស៊ីចង្វាក់គ្នា ១០០% ពីដើមដល់ចប់ និងកំណត់ចំណាំកំហុសប្ដូរកំពូលនេះក្នុង Scenario/Guideline)*។
     - **កំហុស ១b (`Circular Warrant`)**: ដង្កៀបសរុបចុងក្រោយសរសេរថា `ក្នុងត្រីកោណកែង BAC និង B'AC មាន : CB = CB' អ៊ីប៉ូតេនុសប៉ុនគ្នា(សម្មតិកម្ម), ∠B = ∠B'} ដូចនេះ ΔABC ≅ ΔA'B'C' (តាមលកខណ្ឌ អ.ជ)` — ជាការប្រើសំអាង **`អ.ជ` (រង្វង់តក្ក)** ដើម្បីស្រាយទ្រឹស្ដីបទ `អ.ជ` ខ្លួនឯង! ត្រូវកែជា **`(តាមលក្ខខណ្ឌ អ.ម)`** (អ៊ីប៉ូតេនុស $CB = C'B'$ និងមុំស្រួច $\angle B = \angle B'$ ពី §1.3.1)។
     - **កំហុស ១c (`Khmer Typo`)**: សៀវភៅបោះពុម្ពខុស **`លកខណ្ឌ`** (បាត់ជើង `្ខ`) ត្រូវកែជា **`លក្ខខណ្ឌ`** (ដូចដែលសរសេរត្រូវលើទំព័រ `១៥៥`)។
   - **ពំនោលទ្រឹស្ដីបទ `អ.ជ` (ទំព័រ `១៥៥`)**: *«**ទ្រឹស្ដីបទ** : ត្រីកោណកែងពីរប៉ុនគ្នា កាលណាវាមានអ៊ីប៉ូតេនុសប៉ុនគ្នានិងជ្រុងនៃមុំកែងមួយប៉ុនគ្នា ។»*

2. **លំហាត់គំរូ `ប្រសព្វពុះមុំក្នុង` — ទំព័រ `១៥៥` (`pdf_p160.png` & `crop_p160_incenter_full.png`)**:
   - **ខ្លឹមសារប្រធាន**: កន្លះបន្ទាត់ពុះនៃ $\angle B$ និង $\angle C$ របស់ $\triangle ABC$ ប្រសព្វគ្នាត្រង់ $I$។ តាម $I$ គេគូសបន្ទាត់កែងនឹង $AB, BC, AC$ ត្រង់ $D, E, F$ រៀងគ្នា។ `ក. បង្ហាញថា ID = IE = IF`; `ខ. បង្ហាញថាកន្លះបន្ទាត់ AI ជាកន្លះបន្ទាត់ពុះនៃ ∠BAC`។
   - **សម្រាយខ្សែសង្វាក់ ២ ដំណាក់កាល**:
     - `ក.` ប្រើ **`អ.ម (HA)`** ពីរដង៖ $\triangle BEI \cong \triangle BDI \Rightarrow ID = IE$ `(1)` និង $\triangle CEI \cong \triangle CFI \Rightarrow IE = IF$ `(2)` $\Rightarrow ID = IE = IF$។ *(សម្គាល់: $I$ ស្មើចម្ងាយពីជ្រុងទាំងបីនៃត្រីកោណ)*។
     - `ខ.` ប្រើ **`អ.ជ (HL)`** លើ $\triangle IDA$ និង $\triangle IFA$ (អ៊ីប៉ូតេនុសរួម $AI$, ជ្រុងកែង $ID = IF$ ពី `ក.`) $\Rightarrow \angle IAD = \angle IAF \Rightarrow AI$ ជាកន្លះបន្ទាត់ពុះនៃ $\angle BAC$។
   - **ការរកឃើញបន្ទាន់អំពីរូបភាពទំព័រ `១៥៥` (`Unexpected Figure Discrepancies`)**:
     - រូបដើមគូសសញ្ញាស្មើគ្នា **`/`** ទុកមុនលើជ្រុង **`4` អង្កត់គឺ $AD, BD, BE, AF$** (ទាំងដែលប្រធាន *មិនបានឱ្យ $D$ ជាចំណុចកណ្ដាល $AB$ និងមិនបានឱ្យ $AD = AF$ មុនស្រាយ `ខ.` ឡើយ* — ជាអន្ទាក់ទិន្នន័យលើសដែលនាំឱ្យសិស្សលួចប្រើ `SAS` ឬ `SSS` លើ $\triangle IDA, \triangle IFA$ ជំនួស `អ.ជ`)!
     - រូបដើមគូសបន្ទាត់ជាប់ $AI$ និងគូស**ធ្នូមុំស្មើ `/` លើ $\angle DAI$ និង $\angle FAI$ រួចជាស្រេច** (បង្ហាញលទ្ធផល `ខ.` មុនពេលស្រាយ)!
     - $\triangle ABC$ ស្ទើរតែជាត្រីកោណសម័ង្ស ធ្វើឱ្យ $C-I-D$ មើលទៅស្ទើរតែត្រង់ជួរគ្នា។ **ច្បាប់សម្រាប់ Wave 2/3 TikZ**: គូស $\triangle ABC$ ជា**ត្រីកោណសាមញ្ញ (`scalene`)**, គូស **`AI` ជាបន្ទាត់ដាច់ៗ (`គូសបន្ថែម`)**, ដាក់ធ្នូមុំស្មើតែនៅ $B$ និង $C$, ដាក់កែង `90°` ត្រង់ $D, E, F$, និង**ដកសញ្ញា `/` លើ $AD, BD, BE, AF$ និងធ្នូមុំនៅ $A$ ចេញទាំងស្រុង**!

3. **ទ្រឹស្ដីបទប្រសព្វពុះមុំក្នុង & `ប្រតិបត្តិ` — ទំព័រ `១៥៦` (`pdf_p161.png`)**:
   - **ទ្រឹស្ដីបទ**: *«កន្លះបន្ទាត់ពុះមុំក្នុងទាំងបីនៃត្រីកោណមួយប្រសព្វគ្នាត្រង់ចំណុចតែមួយដែលឋិតនៅស្មើចម្ងាយពីជ្រុងទាំងបីនៃត្រីកោណនោះ ។»* (រូបដើមគូសកន្លះបន្ទាត់ពុះ $AI, BI, CI$ ដាច់ៗ, ចំណុច $I$, និងអង្កត់កែង $ID, IE, IF$ ជាប់មានសញ្ញា `90°` ទាំង ៣ ត្រង់ $D, E, F$)។
   - **ប្រតិបត្តិ**: *«$ABC$ ជាត្រីកោណមួយនិង $M$ ជាចំណុចកណ្ដាលនៃជ្រុង $BC$ ។ តាម $M$ គេគូសបន្ទាត់កែងទៅនឹងជ្រុង $AB$ និង $AC$ ត្រង់ $D$ និង $E$ រៀងគ្នា ។ បង្ហាញថា បើ $MD = ME$ នោះ $\angle B = \angle C$ ។»* (រូបគូស $BM = MC$ មាន `|`, $MD \perp AB$ ត្រង់ $D$, $ME \perp AC$ ត្រង់ $E$, `||` លើ $MD = ME$ — ប៉ុន្តែរូបមើលទៅស៊ីមេទ្រីដូចសមបាទស្រាប់ $\to$ បញ្ជាក់សិស្សត្រូវស្រាយ $\triangle BDM \cong \triangle CEM$ តាម **`អ.ជ (HL)`** មិនអាចមើលភ្នែកថា $AB = AC$ ទេ)។

4. **លំហាត់កិច្ចការផ្ទះ (`HW`) — ទំព័រ `១៦៥` (`pdf_p170.png`)**:
   - **លំហាត់ `#១០`**: *«$ABC$ ជាត្រីកោណមួយ ។ កម្ពស់គូសចេញពីកំពូល $B$ និង $C$ កាត់ជ្រុងឈម     ត្រង់ $D$ និង $E$ រៀងគ្នា ។ បង្ហាញថា បើ $BD = CE$ នោះ $\angle ABC = \angle ACB$ ។»* (**Erratum**: ប្រធានដកឃ្លាទទេបាត់ពាក្យ **`AC និង AB`** ក្រោយ `កាត់ជ្រុងឈម`! ឯរូបភាពដាក់សញ្ញា `/` លើ**ផ្នែកខាងក្រោម**នៃកម្ពស់ $BD$ និង $CE$ ជំនួសការបង្ហាញប្រវែងពេញ $BD = CE$ — ត្រូវបកស្រាយ និងបំបែក $\triangle BDC \cong \triangle CEB$ តាម **`អ.ជ (HL)`** ព្រោះអ៊ីប៉ូតេនុសរួម $BC$, $BD = CE$, $\angle BDC = \angle CEB = 90^\circ$)។
   - **លំហាត់ `#១២`**: *«ក្នុងរូបខាងស្ដាំនេះ គេឱ្យ $AC = BD$ និង $\angle C = \angle D = 90^\circ$ ។ បង្ហាញថា $BC = AD$ និង $BC \parallel AD$ ។»* (រូបចតុកោណមានកំពូល $C$ លើឆ្វេង, $B$ លើស្ដាំ, $A$ ក្រោមឆ្វេង, $D$ ក្រោមស្ដាំ, អង្កត់ទ្រូង $AB$ ជាអ៊ីប៉ូតេនុសរួម, `/` លើ $AC, BD$, កែង `90°` នៅ $C, D$ $\to$ ស្រាយ $\triangle ACB \cong \triangle BDA$ តាម **`អ.ជ (HL)`** $\Rightarrow BC = AD$ និង $\angle CBA = \angle DAB$ មុំឆ្លាស់ក្នុងស្មើគ្នា $\Rightarrow BC \parallel AD$)។

## ២. សំយោគភស្តុតាងស្រាវជ្រាវតាមទិដ្ឋភាពទាំង ៤ (Empirical Synthesis Across 4 Lenses)

### ក. ហេតុផល `អ.ជ (HL)` ផុតពីភាពមិនច្បាស់ `SSA` និងបន្ទាត់ជំនួយត្រឡប់រូប (Lens a)
- **គ្រោងឆ្អឹង `APOS` សម្រាប់ `HL` vs `SSA`**: **Yigit Koyunkaya (2018)** បង្ហាញថាការយល់ទំនាក់ទំនងត្រីកោណកែង (`RASR`) ផ្អែកលើទ្រឹស្ដីបទពីតាហ្គ័រ និងលក្ខណៈ *អ៊ីប៉ូតេនុសវែងជាងជ្រុងកែងជានិច្ច*៖ ពេលមុំមិនកែង `SSA` អាចបង្វិលកាំបង្កើតចំណុចប្រសព្វ `២` លើបាត, មុំ $90^\circ$ បង្ខំឱ្យបន្ទាត់កែងបង្កើតត្រីកោណកែងតែមួយគត់។
- **ការកែប្រែរូបដោយបន្ថែមបន្ទាត់ជំនួយ (`Operative Apprehension`)**: **Muzaini, Rahayuningsih, Ikram, & Nasiruddin (2023)** (សម្ភាសន៍គ្លីនិក `12` នាក់ លើសិស្សវិទ្យាល័យ) រកឃើញថា សិស្សភាគច្រើនបកស្រាយពាក្យបានតែសន្និដ្ឋានខុស លុះត្រាតែប្រើ `Operative Apprehension` — ការបត់រូប និងបន្ថែមបន្ទាត់ជំនួយដូចការត្រឡប់ $\triangle A'B'C'$ មកផ្គុំបន្ទាត់ត្រង់ $BB'$ ($\angle BAB' = 180^\circ$, ទំព័រ `១៥៤`) និងការគូសបន្ថែម $AI$ (ទំព័រ `១៥៥`)។
- **អន្ទាក់រូបគំរូសៀវភៅ (`70%` Prototype Diagrams)**: **Tchonang Youkap, Njomgang Ngansop, Tieudjo, & Pedemonte (2020)** រកឃើញថាក្នុងសៀវភៅថ្នាក់ទី៧–៨ **`70%` នៃរូបភាពមានទ្រង់ទ្រាយគំរូដដែលៗ** (`64.29%` proof / `35.71%` empirical; `56%` linear / `46%` conditional theorems) នាំឱ្យសិស្សសន្និដ្ឋានតាមភ្នែក (ដូចគំនូស `/` លើ $AD, BD, BE, AF$ ទំព័រ `១៥៥` និងរូបសមបាទ `ប្រតិបត្តិ` ទំព័រ `១៥៦`)។

### ខ. ចំណុចប្រសព្វកន្លះបន្ទាត់ពុះមុំក្នុង (`Incenter`), ការភ័ន្តច្រឡំចំណុចពិសេស និងការបត់ក្រដាស (Lens b)
- **ការច្រឡំ Incenter vs Circumcenter vs Centroid**: **Demiray, Işıksal-Bostan, & Saygı (2023)** (`N = 6` អនាគតគ្រូឆ្នើម ២ ក្រុម) កត់ត្រាការភ័ន្តច្រឡំដោយផ្ទាល់ថា អនាគតគ្រូសាកល្បងយកប្រសព្វ**កន្លះបន្ទាត់ពុះមុំ**ទៅរក `Circumcenter` (T1) និងបដិសេធ `Medians` ដោយអះអាងថា *«Centroid ជាប្រសព្វពុះមុំក្នុង»* (T3) មុនពេលសាកល្បងកែដោយការសាងសង់។ ដូច្នេះក្នុងមេរៀនត្រូវបញ្ជាក់ការបែងចែក៖ **ពុះមុំ $\to$ ស្មើចម្ងាយពីជ្រុង ៣ (`Incenter`)** ខុសពី *ពុះកែងជ្រុង $\to$ ស្មើចម្ងាយពីកំពូល ៣* និង *មេដ្យាន $\to$ ចំណុចកណ្ដាលជ្រុង*។
- **ចម្ងាយស្មើពីផ្លូវ និងបញ្ហា `Conflict Lines`**: **Šipuš, Bašić, Doorman, Špalj, & Antoliš (2022)** (`~500` & `~200` សិស្ស) បង្ហាញថាសកម្មភាពស្មើចម្ងាយបែបជីវភាពជំរុញសិស្សឱ្យរកឃើញថាចម្ងាយពីចំណុចទៅបន្ទាត់ត្រូវវាស់កែង `90°` មិនមែនខ្សែទ្រេតទេ។
- **ការបត់ក្រដាសថ្លា និងអន្តរាគមន៍ថ្នាក់ទី៨**: **Boz-Yaman (2024)** (`N = 108`: `M = 5.34 → 8.41`, `t(55) = -5.062, p < .005`; self-efficacy `t(106) = 2.238, p = .027`) គាំទ្រការបត់ពុះមុំទាំង ៣ ដោយដៃ។ **Masinading & Gaylo (2022)** (`N = 60` ថ្នាក់ទី៨) រកឃើញថា `86%–94%` ធ្លាក់មុនតេស្តលើការអនុវត្តត្រីកោណប៉ុនគ្នាលើ*ពុះមុំ និងពុះកែង*; ក្រោយប្រើ `Differentiated Scaffolding` (`Show & Tell`, `Pause-Ask-Pause-Review`) ក្រុមពិសោធន៍ឈ្នះ (`M = 13.10 → 18.03`, `ANCOVA F = 6.648, p = .01`, `57%` vs `27%` passing; ទំនុកចិត្តផ្សារភ្ជាប់ `r = .662, r² = 43.80%, p < .001`)។

### គ. ការលុបរង្វង់តក្ក (`Circular Reasoning`) និងសម្រាយខ្សែសង្វាក់ `HA → HL` (Lens c)
- **សម្រាយ Flow-Chart បញ្ចៀសកំហុសរង្វង់តក្ក (`ទំព័រ ១៥៤`)**: **Anwar, Goedhart, & Mali (2023)** (`N = 60`, `C1 = 32, C2 = 28`, `8` សម្ភាសន៍) កំណត់ច្បាស់ថា *ការយកសន្និដ្ឋានមកធ្វើជាសម្មតិកម្ម* គឺជាកង្វះ `Hypothetical Syllogism` (**Circular Reasoning `RelHS2`: `8%/4%/11%`**; `3/15` សិស្សនៅកម្រិតកណ្ដាលធ្វើខុស) — ត្រូវចំកំហុស `(តាមលកខណ្ឌ អ.ជ)` លើទំព័រ `១៥៤`! ការប្រើ `Flow-Chart` + គិតទៅមុខនិងត្រឡប់ក្រោយ បង្កើនកម្រិត `Holistic-Structural` ពី `0%` ទៅ **`50%` (`30/60`)** (`90%` ប្រើ `Flow-Chart` ឬផ្សំ; `T7 = 91%`, `T8 = 85%`)។
- **ឥទ្ធិពលពហុទម្រង់លើកិច្ចការពុះមុំ**: **Anwar, Mali, & Goedhart (2021)** (`N = 125`: `n = 60` ពហុទម្រង់ + `Flow-Chart` vs `n = 65` ២ ជួរ) បង្ហាញថា `N-gain = .733` (`7.25 → 13.75`, High) ខ្ពស់ជាងក្រុមត្រួតពិនិត្យ `.330` (`7.80 → 10.80`, `U(60,65) = 547.5, p < .001`) ដោយ **`56.7%` vs `6.2%`** ឈានដល់ `Beyond Chaining Elements`, ឈ្នះលើ `Logical Status` (`U = 536.5, p < .001`) និង `Summarization` (`U = 833.0, p < .001`), និងប្រើលំហាត់ពុះមុំត្រួតពិនិត្យការប្ដូរលំដាប់ជំហាន។
- **សំអាងលេខ `①–⑤` និងការគិតបញ្ច្រាស**: **Miyazaki et al. (2019)** និង **Tchonang Youkap et al. (2020)** គាំទ្រការដាក់លេខសំអាង `①–⑤` និងការកែច្នៃលទ្ធផល `ID = IE = IF` ជាទិន្នន័យចូលសម្រាប់ដំណាក់កាល `អ.ជ (HL)`។

### ឃ. គម្លាតទម្រង់សម្រាយ ការបំបែកត្រីកោណត្រួតគ្នា និង `[tracing]` (Lens d)
- **Manalo (2025)** (`N = 109` ថ្នាក់ទី៨): `85.32%` ជាប់នៅ `Level 0` និង `0.00%` នៅ `Level 3` លើ `Proof Task 3` ដោយសារខ្វះឧទាហរណ៍គំរូ `Statement–Reason` (p. 24)។
- **Winer & Battista (2022)** (`N = 7`, `84` proofs): `72.5%` (`61/84`) មានគម្លាតទម្រង់ (`27` រំលងសម្មតិកម្ម; `40%` = `65/165` `FG2` ដាក់ឈ្មោះសំអាងខុស; `LG2` រង្វង់តក្ក) $\to$ បង្ខំសិស្សនិយាយផ្ទាល់មាត់ និងសរសេរជ្រុង/អ៊ីប៉ូតេនុសរួម ($AI = AI, BC = BC, AB = AB$) ឱ្យច្បាស់។
- **Biber (2020)** (`N = 55`): ភាពត្រឹមត្រូវធ្លាក់ **`92% → 82% → 53%`** ពេលត្រីកោណត្រួតគ្នា $\to$ ត្រូវបំបែករូប `២` ផ្ទាំងដាច់ពីគ្នាក្នុង `Ex. #10` ($\triangle BDC, \triangle CEB$) និង `Ex. #12` ($\triangle ACB, \triangle BDA$)។
- **Yeo & Tzeng (2019)** (`N = 72`): `[tracing]` បង្កើនការផ្ទេរ (`F(1,68) = 9.38, p = .003, η² = .121`) និងកាត់បន្ថយអារម្មណ៍លំបាក (`p < .001`) លើគំរូ `Incenter` និង `ប្រតិបត្តិ`។
